## ✨ Key Features  

### 1. **Quran Explorer**  
- **Ayah by Ayah Mode**:  
  - Listen to recitation for each Ayah (hover/click to play).  
  - Tafseer (explanations) displayed per Ayah (toggleable).  
  ![Quran Ayah Mode](./assets/quran-ayah.png) *(Example: Ayah with audio controls)*  

- **Page by Page Mode**:  
  - Traditional Mushaf layout with page navigation.  
  - Jump to any Surah/Page via search or index.  
  - Bookmark and annotate pages.  
  ![Quran Page Mode](./assets/quran-page.png) *(Example: Quran page with navigation toolbar)*  

### 2. **Azkar & Hadiths**  
- Daily morning/evening Azkar with reminders.  
- Curated Hadith collections (Sahih Bukhari, Muslim, etc.).  
- Search/filter by topic or keyword.  
  ![Azkar Section](./assets/azkar.png) *(Example: Azkar cards with categories)*  

### 3. **Prayer Times & Qibla**  
- Accurate prayer times based on location.  
- Qibla compass with AR overlay *(if implemented)*.  
- Mosque finder (optional integration with Google Maps).  
  ![Prayer Times](./assets/prayer-times.png) *(Example: Prayer schedule with Qibla arrow)*  

### 4. **Tafseer & Learning Tools**  
- Explanations from trusted scholars (Ibn Kathir, Jalalayn, etc.).  
- Word by word translation and root word analysis.  
- Highlight and save notes.  

## 🛠️ Technical Implementation  
- **Quran Audio**: From API then handle it by audio controllers.  
- **Navigation**: Swipe gestures for Surah/Page switching.
- **Light/Dark Mode**: Supports light and dark mode.
